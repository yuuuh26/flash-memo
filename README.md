# FLASH MEMO

v1.0.0 · Made by YUU

高速入力を中心にした、Android Chrome向けの端末内メモPWA。

公開URL: https://yuuuh26.github.io/flash-memo/

## 使い方

1. 「書く」で本文を入力。約400ms後に自動保存します。
2. 「次のメモ」で確定し、同じタグで続けて入力します。
3. 「メモ一覧」で検索・編集・コピー。複数選択でタグ編集・マージ・削除できます。
4. 「設定・管理」でタグ、バックアップ、ゴミ箱を管理します。

タグは自由に作成し、クイックタグの表示・順序を変更できます。長文と複数画像に対応します。メモと画像は外部に送信しません。

## 保存とバックアップ

IndexedDB `flash-memo-db` にmemos / tags / attachments / settings / backupStateを分離して保存します。書き込み完了はトランザクションのcompleteで判定します。起動時は前回のドラフトを復元します。対応環境ではWeb Locksで複数タブからの同時編集を防止します。

新規メモ15件ごとに、入力確定後にバックアップを案内します。JSONは画像も含みます。ダウンロード一覧でファイルを確認し「確認できた」を押すと、出力した時点までを確認済みとします。出力後に作ったメモは次のカウントへ残ります。

追加・統合では同じIDの現在のデータを優先します。全置換では置換前バックアップと確認を求めます。インポート全体を検証してから、単一トランザクションで反映します。画像のUndo用に残した未参照データはエクスポートから除外します。

ブラウザのデータ削除、端末の故障等に備え、定期的にバックアップしてください。端末間の自動同期はありません。

## 構成

- `js/app.js`: 画面と操作フロー
- `js/db.js`: IndexedDB / トランザクション
- `js/model.js`: メモ・タグ関連、マージ、Undo / Redo
- `js/backup.js`: JSON検証・画像変換・統合・ダウンロード
- `sw.js`: アプリ資産のみのオフラインキャッシュ
- `manifest.webmanifest`: `/flash-memo/` 固有のPWA識別

アプリ更新でIndexedDBは削除しません。DBバージョン変更時はマイグレーションを追加します。新バージョンのService Workerは旧タブが閉じた後に切り替わります。キャッシュ削除はFLASH MEMOのアプリ資産だけを対象とします。

## ローカル実行・検証

ビルド不要の静的HTML / CSS / ES Modulesです。

```sh
npm install
npm test
# 親ディレクトリを公開し /flash-memo/ へアクセス
python3 -m http.server 8000 --directory ..
```

テストはjsdom / fake-indexeddbを使った操作とDB検証です。Android実機のキーボード・PWAインストール・OSアイコン形状は別途実機確認が必要です。
